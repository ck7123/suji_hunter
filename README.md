# すうじハンター！ 設置・遊び方ガイド

## フォルダ構成
```
suji-hunter/
├ index.html  ゲーム本体      ├ style.css  デザイン     ├ script.js  ゲームの処理
├ qr-print.html QR印刷ページ  ├ qr-codes.pdf 1〜5のQR印刷用PDF
├ sw.js オフライン用          ├ lib/ QR読取(jsQR)・QR生成ライブラリ
└ tools/make_pdf.py PDF再作成用（不要なら無視）
```
キャラクターは絵文字、効果音は端末内で生成、読み上げはiPad標準の音声を使うので、画像・音声ファイルは不要です。

## 1. ファイルの保存
ZIPを解凍し、フォルダ構成を崩さずそのまま保存します。

## 2. 起動方法（重要）
iPadのカメラは **HTTPS** のページでしか使えません（パソコンのファイルを直接開いても動きません）。いちばん簡単な方法：
1. https://app.netlify.com/drop を開く（無料）
2. `suji-hunter` フォルダごと画面にドラッグ＆ドロップ
3. 発行された `https://〜.netlify.app` のURLをiPadのSafariで開く
（GitHub Pages / Cloudflare Pages でもOK。カメラ映像や個人情報は外部に送信しません。）

## 3. iPadで遊ぶ
Safariでアドレスを開き、共有ボタン→「ホーム画面に追加」で次回から1タップ。横向き推奨。一度開けば、オフラインでも動きます。
「ゲームスタート」→数字のQRを2つ見つける→足し算に答える→ハート5個でクリア。
ハートは0個から始まり、正解ごとに増えて5個でクリアです（設定で個数変更可）。1回まちがえるとヒント、2回まちがえると正解を教えてハートが1個へり、次の問題へ進みます。

## 4. カメラの許可
初回に「カメラへのアクセスを求めています」と出たら「許可」。拒否した場合は
設定アプリ→Safari→カメラ→「確認」または「許可」、またはアドレスバーの「ぁあ」→Webサイトの設定→カメラ→許可。

## 5. QRコードの印刷
- `qr-codes.pdf`：A4に1〜5を印刷（1枚に5つ）。
- または タイトル画面の「QRコードを印刷」→数字を入力→「印刷」。6を追加したい場合は `1,2,3,4,5,6` のように入力（設定の最大値も上げてください）。
- 数字の下の大きな文字つき。切り取って部屋の低い位置にも貼ると、お子さんが見つけやすいです。同じ数字は何枚貼ってもOK。

## 6. 保護者向け設定
タイトル画面の**右上の角を2秒長押し**。数字の範囲・選択肢数(3〜5)・ハート数・音声・効果音を変更できます。

## 7. 困ったとき
- **カメラが映らない**：HTTPSのURLか確認／許可設定を確認／他のアプリがカメラを使っていないか確認。
- **QRを読まない**：明るい場所で、QRを画面の中央に20〜30cmで。ゆらさず1秒ほど。
- **声が出ない**：iPadの消音スイッチ・音量を確認。声が出なくても画面表示で遊べます。
- **更新が反映されない**：Safariを閉じて開き直す（`sw.js` の `suji-v1` を `suji-v2` に変えて再アップロード）。
